# Smartslate Brand Design Guide — DEPRECATED

This file has been superseded by **[STYLE.md](./STYLE.md)**.

The canonical, codebase-specific design system for AI Foundations lives
in `STYLE.md`. It defines:

- The **two-accent rule** — Brand Teal (`#a7dadb`) for design spotlight,
  Brand Indigo (`#4F46E5`) for CTA action.
- The **glassmorphism ideology** — every elevated surface is frosted glass
  over the deep navy (`#020C1B`) stage.
- The **canvas-fit HARD rule** — every slide must fit inside the 16:10
  `CanvasViewer` rectangle; no bleed on any side.
- Fonts (Quicksand headings / Lato body), spacing, radius, motion, and
  reduced-motion guidance.
- A copy-paste token block matching `src/app/globals.css`.

Please update `STYLE.md` (and `globals.css`) when the design system changes.
This file is retained only as a historical reference for the original
Smartslate brand guide.
