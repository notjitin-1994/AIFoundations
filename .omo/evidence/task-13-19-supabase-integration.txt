# Task 13-19: Supabase Integration — useLRS hook and media URL utilities

## Evidence log

### Created `src/hooks/use-lrs.ts`
- Client-side hook wrapping `sendXAPIStatement` from `@/actions/xapi`
- Exports `useLRS()` returning `{ track }`
- `track` accepts verb, verbDisplay, objectId, objectName, optional objectDescription, and optional context with moduleId/slideId/lessonIndex/result
- Errors are logged to console without blocking the caller

### Created `src/lib/media.ts`
- Reads `NEXT_PUBLIC_SUPABASE_URL` environment variable
- Exports three utilities:
  - `audioUrl(filename)` → `${SUPABASE_URL}/storage/v1/object/public/course-audio/${filename}`
  - `imageUrl(filename)` → `${SUPABASE_URL}/storage/v1/object/public/course-images/${filename}`
  - `videoUrl(filename)` → `${SUPABASE_URL}/storage/v1/object/public/course-videos/${filename}`
